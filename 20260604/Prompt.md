## 對話 4：原始需求（第一版，範圍較大）

```
請組成專家團隊，其中包含健康專家。

請產生個人的健康運動儀表板。
其中包含安靜心率的日期趨勢圖，沒有安靜心率的日期不用出現在趨勢圖裡面，
預設顯示最近 30 筆的安靜心率趨勢圖，可以自訂日期範圍。
選擇日期的時候，沒有安靜心率的日期會用灰色表示。
也可以用年份選擇，例如選擇 2023 等等。
如果選擇的年份，或者時間範圍沒有安靜心率，請顯示「沒有安靜心率」

新的檔案都放在 20260604 資料夾裡面。

1：除了安靜心率(RHR)趨勢圖以外，包含以下的數據：
  • 每日步數 (steps / 卡路里)
  • 心率 (heart_rate，非安靜心率)
  • 血氧 SpO₂
  • 睡眠 (睡眠時長、分數)
  • 壓力 (stress)
  • 運動紀錄 (sport_record)

2：單一 HTML 檔案
3：月曆式的日期選擇器（可以看到整個月，沒有資料的日期呈灰色）
4：文字形式的健康建議，加上圖表視覺化，兩者都要
5：加上警語，例如 AI 可能會出錯，只提供健康建議非醫療診斷，需要醫生專業評估之類的提醒。
```

## 使用提示（供未來延伸開發參考）

若要重新開發或交付給新的 AI 工具，可使用以下精簡版提示詞：

```
我有小米運動健康 App (MiFitness) 匯出的 CSV 資料，位於：
/Users/wuzhongxiong/Documents/geminiCLI/geminiCLI_MiFitness_20260521/data/

其中安靜心率 (Resting Heart Rate, RHR) 數據共 140 筆（2023-11-15 至 2026-05-20），
每日一筆，儲存在 20260521_6499811869_MiFitness_hlth_center_fitness_data.csv 中，
Key 為 resting_heart_rate，Value 為 {"bpm": 94, "date_time": 1700006400} 格式。

請建立一個 Flask + HTML 儀表板（新檔案放在 20260604 資料夾），功能如下：
1. 安靜心率折線趨勢圖（預設最近 30 筆）
2. 月曆式日期範圍選擇器（無資料日期呈灰色不可選）
3. 年份下拉選單（2023/2024/2025/2026），無資料時顯示「沒有安靜心率」
4. AI 健康建議文字（根據平均 BPM 給出不同等級的建議）
5. 醫療免責聲明警語

時區：台北時區 UTC+8
```
