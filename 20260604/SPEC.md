## 後端規格 (`app.py`)

### 資料讀取

- **來源：** `20260521_6499811869_MiFitness_hlth_center_fitness_data.csv`
- **Key 篩選：** `resting_heart_rate`, `rhr`, `resting_hr`, `resting heart rate`
- **時間戳：** Unix Timestamp 轉換為台北時區 (UTC+8)，取出 `YYYY-MM-DD`
- **資料格式：** `{ "2023-11-15": 94, "2023-11-16": 96, ... }`
- **啟動時自動載入資料**

### API 端點

#### `GET /`
- 回傳：`templates/index.html` 頁面

#### `GET /api/available_dates`
- 功能：回傳所有有 RHR 資料的日期列表
- 回傳格式：`["2023-11-15", "2023-11-16", ...]`
- 用途：提供給前端 Flatpickr，標記有資料的日期（無資料日期呈灰色）

#### `GET /api/rhr`
- 功能：取得 RHR 資料
- Query 參數：
  - `start` (optional)：起始日期 `YYYY-MM-DD`
  - `end` (optional)：結束日期 `YYYY-MM-DD`
  - `limit` (optional, int)：筆數限制（僅在無 start/end 時生效）
- 預設行為：無參數時回傳最近 30 筆
- 回傳格式：`[{"date": "2023-11-15", "bpm": 94}, ...]`

#### `POST /api/analysis`
- 功能：根據傳入的 RHR 資料，產生健康建議文字
- Request Body：`{ "data": [{"date": "...", "bpm": 94}, ...] }`
- 分析邏輯：

| 平均 BPM | 建議內容 |
|---|---|
| < 60 | 心率偏低，可能為運動員體質，需留意頭暈 |
| 60 ~ 75 | 理想健康範圍，維持現有習慣 |
| 76 ~ 85 | 正常偏高，建議加強有氧運動與壓力管理 |
| > 85 | 偏高，可能與壓力/睡眠不足有關，建議諮詢醫師 |

- 回傳格式：`{ "advice": "..." }`（支援 `**粗體**` Markdown 格式）

## 前端規格 (`templates/index.html`)

### 頁面結構

1. **頁首 Header**：標題「安靜心率 (RHR) 趨勢儀表板」
2. **警語區塊**：黃色背景，顯示 AI 免責聲明
3. **篩選控制區**：
   - 年份下拉選單 (年份: 2023, 2024, 2025, 2026, 2056)
   - Flatpickr 月曆日期範圍選擇器
   - 重置按鈕
4. **專家建議區**：藍色背景，動態顯示 AI 分析文字
5. **圖表區**：Chart.js 折線圖，或顯示「沒有安靜心率」提示

### 日期選擇器行為

- 使用 Flatpickr，mode: `"range"`
- `enable` 設定為 `/api/available_dates` 回傳的日期陣列
- **有資料的日期** → 可正常點選
- **無資料的日期** → 呈現灰色，無法點選
- 選定完整範圍後，自動呼叫 `/api/rhr?start=&end=` 更新圖表

### 年份選擇器行為

- 選擇年份後，自動清空日期選擇器
- 以 `{year}-01-01` 到 `{year}-12-31` 為範圍呼叫 API
- 若該年份無資料，顯示「沒有安靜心率」

### 重置按鈕行為

- 清空年份選單
- 清空日期選擇器
- 重新載入最近 30 筆 RHR 資料

### 無資料處理

- 圖表區隱藏，改顯示「沒有安靜心率」文字（大字居中）
- 專家建議區顯示「沒有安靜心率，無法進行分析」

### Chart.js 圖表設定

- 類型：`line`（折線圖）
- X 軸：日期
- Y 軸：BPM（建議範圍 40~100）
- 顏色：藍色系（`rgb(59, 130, 246)`）
- 啟用填色 (`fill: true`)、平滑曲線 (`tension: 0.3`)

## 不在範圍內的功能 (Out of Scope)

以下功能已討論過，但在最終規格中**不包含**：
- 每日步數 / 卡路里圖表
- 非安靜心率 (即時心率) 圖表
- 血氧 SpO₂ 圖表
- 睡眠時長與分數圖表
- 壓力 (Stress) 圖表
- 運動紀錄 (Sport Record) 列表
